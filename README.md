# Portal Água Azul do Norte

Site estático com páginas HTML, CSS e JavaScript. O deploy é feito pelo GitHub Actions para o GitHub Pages.

## Publicar

1. Envie o conteúdo desta pasta para a raiz de um repositório GitHub chamado `agua-azul-do-norte`.
2. Em **Settings → Pages**, escolha **GitHub Actions** como origem da publicação.
3. Envie ou atualize arquivos na branch `main`. O workflow em `.github/workflows/pages.yml` publicará o site automaticamente.
4. Quando o primeiro deploy terminar, o endereço será `https://SEU-USUARIO.github.io/agua-azul-do-norte/`.

Este repositório não acompanha automaticamente o arquivo de informações guardado em Documentos. Para refletir novas informações no portal, atualize os arquivos do site e envie as alterações ao repositório.
